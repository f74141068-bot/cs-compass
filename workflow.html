PROJECT HANDBOOK / V1.0

讓 AI 有一套
可以遵循的工作方式。

AGENTS.md 是本專案的開發手冊。把內容結構、設計限制與完成條件明文化，使不同 AI 都能依照相同方式新增筆記。

查看 AGENTS.md →
01

讀取規則

先閱讀 AGENTS.md 與現有資料，確認允許修改的範圍。

02

新增內容

在 content/notes.json 增加唯一 ID 的筆記，填寫固定欄位。

03

產生頁面

執行 build.py，自動生成首頁卡片、筆記頁與導覽。

04

驗收成果

執行 check.py，並以瀏覽器檢查搜尋、連結及版面。

EXTENSION CASE / 001

擴充案例：二元搜尋 Binary Search
