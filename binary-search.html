二元搜尋 Binary Search

在已排序陣列中反覆縮小搜尋範圍，以對數時間找到目標。

ON THIS PAGE

01 核心觀念02 C++ 實作03 複雜度04 常見錯誤05 自我測驗

01 / 核心觀念

  • 先確認陣列由小到大排序。
  • 維護半開區間 [left, right)，每次檢查中點。
  • 若中點值比目標小，就令 left = mid + 1；若較大，就令 right = mid。

02 / C++ 實作

C++17 · 可獨立編譯範例
#include <iostream>
#include <vector>
int binarySearch(const std::vector<int>& a, int target) {
    int left = 0, right = static_cast<int>(a.size());
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (a[mid] == target) return mid;
        if (a[mid] < target) left = mid + 1;
        else right = mid;
    }
    return -1;
}
int main() {
    std::vector<int> a{2, 4, 6, 8, 10};
    std::cout << binarySearch(a, 8) << '\n';
}

輸出 3，即 8 的索引。找不到時回傳 -1；若有重複值，只保證回傳其中一個符合的索引。

03 / 複雜度

已排序的 n 個元素，最壞 O(log n) 時間；迭代版本額外空間 O(1)。

04 / 常見錯誤

不要直接套用在未排序資料；半開區間的 right 初值是 size()，不可把閉區間的更新方式混用。

05 / 自我測驗

在 [2, 4, 6, 8, 10] 尋找 7，最後回傳什麼？

展開參考答案

-1，因為搜尋範圍縮小至空區間後仍未找到 7。
