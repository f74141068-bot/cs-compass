C++ 基礎 入門

指標 Pointer

理解記憶體位址、解參考與 nullptr，為鏈結串列打好基礎。

ON THIS PAGE

01 / 核心觀念

  • 指標儲存物件的位址；&x 取得 x 的位址。
  • *p 取得 p 指向的物件，可以透過它修改該物件。
  • nullptr 表示未指向有效物件；不能對它解參考。

02 / C++ 實作

C++17 · 可獨立編譯範例
#include <iostream>
int main() {
    int x = 10;
    int* p = &x;
    *p = 20;
    std::cout << x << '\n';
}

p 指向 x，因此 *p = 20 直接改變 x；輸出 20。

03 / 複雜度

此範例的操作皆為 O(1) 時間，額外空間 O(1)。

04 / 常見錯誤

不要對 nullptr 或生命週期已結束的物件位址解參考，也不要使用未初始化的指標。

05 / 自我測驗

若 int x = 3; int* p = &x; *p = 8;，x 的值是多少？

展開參考答案

8，因為 *p 操作的是 x 本身。
