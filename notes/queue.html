佇列 Queue

理解先進先出 FIFO，辨認與堆疊的操作差異。

ON THIS PAGE

01 核心觀念02 C++ 實作03 複雜度04 常見錯誤05 自我測驗

01 / 核心觀念

  • Queue 是 First In, First Out (FIFO) 的資料結構。
  • push 將元素加入尾端，pop 移除前端元素，front 查看前端。
  • 排隊與廣度優先搜尋 (BFS) 都可使用佇列的先進先出特性。

02 / C++ 實作

C++17 · 可獨立編譯範例
#include <iostream>
#include <queue>
int main() {
    std::queue<int> q;
    q.push(10);
    q.push(20);
    while (!q.empty()) {
        std::cout << q.front() << ' ';
        q.pop();
    }
}

輸出 10 20，因為最早加入的元素最早被移除。

03 / 複雜度

預設 deque 底層的 push、pop、front 為 O(1) 時間，n 個元素使用 O(n) 空間。

04 / 常見錯誤

std::queue 使用 front() 而不是 top()；在空佇列上不可呼叫 front 或 pop。

05 / 自我測驗

依序 push 5、7、9；pop 一次後，front 是多少？

展開參考答案

7，因為 5 已先被移除。
