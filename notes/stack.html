堆疊 Stack

認識後進先出 LIFO，以及 push、pop、top 的基本操作。

ON THIS PAGE

01 核心觀念02 C++ 實作03 複雜度04 常見錯誤05 自我測驗

01 / 核心觀念

  • Stack 是 Last In, First Out (LIFO) 的資料結構。
  • push 加入頂端；pop 移除頂端；top 查看頂端。
  • C++ std::stack 的 pop 不回傳元素，須先使用 top 讀取。

02 / C++ 實作

C++17 · 可獨立編譯範例
#include <iostream>
#include <stack>
int main() {
    std::stack<int> s;
    s.push(10);
    s.push(20);
    if (!s.empty()) {
        std::cout << s.top() << '\n';
        s.pop();
    }
    std::cout << s.top() << '\n';
}

20 最後進入，所以先輸出 20；移除後，頂端是 10。

03 / 複雜度

以預設 deque 作為底層容器時，push、pop、top 為 O(1) 時間，n 個元素使用 O(n) 空間。

04 / 常見錯誤

空堆疊不可呼叫 top 或 pop；操作前先確認 empty()。

05 / 自我測驗

依序 push 1、2、3，再 pop 一次，此時 top 是多少？

展開參考答案

2。3 是最後加入的元素，因此最先被移除。
