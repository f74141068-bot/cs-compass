資料結構 入門

單向鏈結串列 Linked List

用 Node* 與 next 串起節點，熟悉走訪與記憶體釋放。

ON THIS PAGE

01 / 核心觀念

  • 每個 Node 儲存資料 data 與下一個節點的位址 next。
  • head 指向第一個節點；最後一個節點的 next 為 nullptr。
  • 走訪時可使用額外指標 cur，以免改變代表串列起點的 head。

02 / C++ 實作

C++17 · 可獨立編譯範例
#include <iostream>
struct Node { int data; Node* next; };
int main() {
    Node* head = new Node{10, new Node{20, nullptr}};
    for (Node* cur = head; cur != nullptr; cur = cur->next)
        std::cout << cur->data << ' ';
    while (head != nullptr) {
        Node* old = head;
        head = head->next;
        delete old;
    }
}

依序輸出 10 20，再逐一釋放節點。先取得下一個節點，才能安全刪除目前的節點。

03 / 複雜度

走訪 n 個節點需要 O(n) 時間；額外走訪空間 O(1)，串列本身占 O(n) 空間。

04 / 常見錯誤

先 delete 再讀取該節點的 next 會造成未定義行為。

05 / 自我測驗

若 head 指向 10，10 的 next 指向 20，走訪何時停止？

展開參考答案

當 cur 變成 nullptr 時停止；10 和 20 都會被讀取。
